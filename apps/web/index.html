Setu

Headset setup

Steps

    Before you start

    • Turn on Developer Mode for the headset, in the Meta Horizon app on your phone.
    • Use a USB-C cable that carries data, not only charge.
    • Close SideQuest and Meta Quest Link, and run adb kill-server if you use adb: only one program can use the headset's USB connection.
    Setu sends your Quest's audio to your PC. Source and docs on GitHub.
